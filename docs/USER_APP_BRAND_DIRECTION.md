# 趣集用户端视觉语言 → 后台迁移方案

## 设计判断

采用 **Redesign · Preserve（保留式品牌化重构）**。不改变现有活动中心化信息架构、权限、入驻审核、票务、角色服装道具和现场管理流程，只重构视觉令牌与关键组件表现。

> 核心原则：同一品牌，不同工作场景。用户端可以活泼、强视觉；管理后台必须克制、清晰、可靠，但需要让人一眼看出属于同一个“漫圈 / 趣集”体系。

## 从用户端设计稿提取的稳定特征

1. **品牌主色**：蓝紫、薰衣草紫、桃粉组成的连续色阶；深海军蓝用于图标和高对比信息。
2. **背景层次**：近白偏冷的雾蓝背景，局部使用柔和紫色光晕，不使用大面积浓烈渐变。
3. **容器语言**：白色卡片、约 12–18px 圆角、极浅阴影，模块之间用留白而不是粗边框分割。
4. **操作语言**：主操作使用紫粉渐变胶囊按钮；次操作保持白底、紫色描边；禁用态使用低对比灰紫。
5. **状态与标签**：浅紫底、紫色文字的小型胶囊标签；成功、警告、异常仍保留业务语义色，避免所有状态都变紫。
6. **图标与角色资产**：圆形或圆角图标底座，深蓝图标；角色 IP 只在登录、成功态、空状态等低频位置出现，不进入高密度表格和审核区。
7. **排版**：标题用深黑/深蓝，正文保持 14–16px，辅助信息不低于 13px；长句按语义换行，不逐字断行。
8. **动效**：按钮 120–160ms 按压反馈，抽屉和弹窗 180–240ms；不使用漂浮光球、持续闪烁和大面积炫光。

## 后台设计校准

- **视觉变化强度**：5/10
- **动效强度**：3/10
- **信息密度**：8/10
- **资产依赖**：4/10
- **品牌一致性**：9/10

## 后台落地边界

| 用户端元素 | 后台采用方式                           | 不采用方式                       |
| ---------- | -------------------------------------- | -------------------------------- |
| 紫粉渐变   | 登录主按钮、核心提交按钮、当前流程节点 | 整页背景、所有卡片、所有状态标签 |
| 柔和紫色底 | 选中菜单、信息提示、空状态             | 数据表格大面积铺色               |
| IP 角色    | 登录角标、审核完成、空状态             | 工作台高频模块、正文装饰         |
| 大圆角卡片 | 登录、欢迎区、重点流程卡片             | 表格、筛选栏、密集业务模块       |
| 深蓝图标   | 导航、功能入口、核验状态               | 多色随机图标                     |

## 第一版建议改造范围

1. 全局品牌色、圆角、阴影和焦点态令牌。
2. 登录页品牌标识、角色选择卡与主按钮。
3. 侧边栏选中态、顶部状态区和当前角色信息。
4. 工作台近期活动、待办、关键数据和异常模块。
5. 入驻认证流程、材料卡、审核状态与主操作按钮。
6. 活动详情生命周期、票务按钮和空状态。

## 已确认的实施令牌

- 主色 `#7357E8`，强主色 `#5B3FC7`
- 品牌桃粉 `#F074B6`，品牌深蓝 `#263B6B`
- 画布 `#F7F7FC`，浅紫表面 `#F3F0FF`，白色表面 `#FFFFFF`
- 正文 `#27304A`，辅助文字 `#69708A`，描边 `#E7E4F2`
- 面板圆角 `14px`，按钮圆角 `10px`，胶囊状态 `999px`
- 主按钮渐变 `linear-gradient(100deg, #F074B6 0%, #B75AF0 52%, #7357E8 100%)`
- 轻投影 `0 10px 30px rgba(61, 45, 119, 0.07)`，浮层投影 `0 20px 56px rgba(45, 32, 100, 0.16)`
- 交互动效 140–220ms，仅动画 `transform` 和 `opacity`；进入使用 `cubic-bezier(0.23, 1, 0.32, 1)`

## 用户端角色素材使用边界

已从用户提供的角色设定稿中提取紫色角色形象。该素材仅用于登录、引导、完成态与角色服装道具资料预览等低频场景，不进入高密度表格和日常审核操作区，避免降低后台信息效率。

## 验收标准

- 不改变现有路由、权限和业务状态机。
- 任何文字不得出现逐字纵排或因品牌化而缩小。
- 业务状态色仍有明确语义，紫色不取代成功、警告、异常色。
- 1280px 桌面与 768px 平板下保持信息密度；375px 下页面可正常堆叠。
- 所有原有可点击入口保持可操作，焦点态与禁用态可辨识。
